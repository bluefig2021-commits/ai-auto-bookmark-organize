크롬 북마크 가져오기
크롬에서 내보낸 bookmarks.html 파일을 넣으면 기존 데이터 뒤에 추가됨.
카테고리 관리
카테고리는 대분류 → 소분류 구조야. 네가 직접 대분류를 추가하고, 각 대분류 안에 소분류를 여러 개 만들 수 있어. 이름 변경·삭제도 여기서 함. AI는 여기 등록된 카테고리만 선택함.
AI 자동 분류
이 브라우저의 localStorage에 저장됨.
현재 북마크를 AI가 보고 대분류 + 소분류를 자동 지정함. 제목과 URL은 그대로 유지함.
대분류는 현재 카테고리 목록 안에서만 선택함. 네가 카테고리를 추가/수정하면 AI 기준도 같이 바뀜. 성인물은 AI에 보내지 않고 NONE 처리함.
